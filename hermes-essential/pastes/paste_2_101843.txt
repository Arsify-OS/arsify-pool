Hermes Agent: Tools & Skills Overview                                                                                                            
     TOOLS (Built-in) — 27 tools                                                                                                                      
     Browser (10 tools)                                                                                                                               
     Fungsi: Mengontrol browser secara otomatis, seperti manusia mengoperasikan web.                                                                  
                                                                                                                                                      
     | Tool | Fungsi | Manfaat |                                                                                                                      
     |------|--------|---------|                                                                                                                      
     | browser_navigate | Buka URL | Akses halaman web otomatis |                                                                                     
     | browser_snapshot | Ambil struktur halaman | Lihat elemen interaktif (tombol, form, link) |                                                     
     | browser_click | Klik elemen | Interaksi dengan tombol, menu, checkbox |                                                                        
     | browser_type | Ketik teks | Isi form, search box, login |                                                                                      
     | browser_press | Tekan keyboard | Submit form (Enter), navigasi (Tab), shortcut |                                                               
     | browser_scroll | Scroll halaman | Lihat konten di bawah/atas viewport |                                                                        
     | browser_back | Kembali ke halaman sebelumnya | Navigasi mundur |                                                                               
     | browser_console | Baca console JS | Debug error JavaScript, cek API calls |                                                                    
     | browser_get_images | List semua gambar | Temukan gambar untuk analisis |                                                                       
     | browser_vision | Screenshot + analisis AI | Pahami layout visual, CAPTCHAs, desain kompleks |                                                  
                                                                                                                                                      
     Manfaat keseluruhan: Otomatisasi web scraping, testing, form filling, dan interaksi dengan aplikasi web tanpa API.

     Kesimpulan                                                                                                                                       
                                                                                                                                                      
     27 built-in tools = kemampuan dasar agent (browser, terminal, file, web, memory, scheduling, communication, media)                               
                                                                                                                                                      
     90+ skills = pengetahuan domain spesifik yang mengubah agent dari "bisa melakukan sesuatu" menjadi "melakukannya dengan benar sesuai best        
     practices"                                                                                                                                       
                                                                                                                                                      
     Kombinasi keduanya membuat Hermes Agent bisa:                                                                                                    
     1. Otomatisasi infrastruktur — deploy, monitor, backup                                                                                           
     2. Software development — code, test, review, debug                                                                                              
     3. Riset & analisis — cari data, analisis, laporan                                                                                               
     4. Konten kreatif — gambar, diagram, musik, video                                                                                                
     5. Komunikasi — email, social media, messaging                                                                                                   
     6. Self-maintenance — update diri sendiri, fix issues
