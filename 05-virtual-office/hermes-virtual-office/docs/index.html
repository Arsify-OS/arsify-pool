📖 Overview

Upshalter Workstation adalah infrastruktur VPS yang menjalankan ekosistem Hermes Agent secara terdistribusi. Dibangun di atas VPS workstation.upshalter.com, sistem ini mengintegrasikan:

  • Hermes Workspace — Development environment berbasis browser (Vite + Node.js)
  • Hermes Kanban — Task management & agent instruction board
  • Hermes Dashboard — Workforce command center untuk memberi instruksi agent menggunakan skill mereka
  • Hermes Orchestrator — Multi-agent task routing & shared memory (SKP)
  • 5 Specialized Agents — hermes-cli, hermes-debug, loyx, gamedev, infra

Semua layanan diakses melalui satu domain dengan path-based routing via Nginx reverse proxy, dilengkapi API Key authentication untuk endpoint API.

🎯 Tujuan

Menyediakan infrastruktur AI Agent yang stabil, terukur, dan mudah diakses untuk pengembangan software, game dev, dan otomasi infrastruktur.

🏗️ Arsitektur

Nginx Path-Based Routing

Semua layanan dipisahkan berdasarkan path di bawah domain utama:

workstation.upshalter.com
├── /hermes/          → Dashboard (static HTML)
├── /hermes/workspace/→ Hermes Workspace (proxy :3000)
├── /hermes/kanban/   → Hermes Kanban (proxy :3000)
├── /hermes/api/*     → Orchestrator API (proxy :8000 + API Key)
└── /hermes/ws        → WebSocket Orchestrator

Nginx otomatis menambahkan header X-API-Key untuk semua request ke /hermes/api/.

Shared Knowledge Pool (SKP)

Semua agent berbagi memory persisten di /root/.hermes via volume mounts:

  • Docker containers (loyx, gamedev): mount /root/.hermes:/opt/data
  • systemd services: akses langsung /root/.hermes
  • Permission: user: root di Docker Compose

Environment Variables

Workspace production startup memerlukan:

HOST=0.0.0.0
TRUST_PROXY=1
COOKIE_SECURE=0  # set 1 setelah SSL
CLAUDE_PASSWORD=<mandatory for remote>

Docker Compose setups perlu extra_hosts untuk akses Ollama di host:

extra_hosts:
  - "host.docker.internal:host-gateway"
