PERUBAHAN YANG DILAKUKAN
-------------------------
1. Update config.yaml di container:
   - model.default = "kr/claude-sonnet-4.5"
   - model.provider = "custom"
   - model.base_url = "http://host.docker.internal:20128/v1"

2. Update .env di container:
   - Tambah OPENAI_API_KEY=sk_9router

3. Update docker-compose.yml:
   - Tambah extra_hosts untuk akses host.docker.internal
   - Mapping: host.docker.internal -> host-gateway

4. Restart container untuk apply perubahan

TROUBLESHOOTING
---------------
Jika connection error:
1. Cek 9router running: pm2 list
2. Cek extra_hosts di docker-compose.yml
3. Test dari container: docker exec hermes-agent-loyx-hermes-agent-1 curl http://host.docker.internal:20128
4. Cek logs: tail -f /root/.9router/log.txt
